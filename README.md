# VERDICT

Быстрые ответы и оформление форума для администрации Black Russia.

## Установка

1. Поставь расширение **Tampermonkey**. В Chrome, Edge и Яндекс Браузере в настройках расширения включи «Разрешить пользовательские скрипты».
2. Нажми ссылку, откроется Tampermonkey с кнопкой «Установить»:

   ### [➜ Установить VERDICT](https://www.tampermonkey.net/script_installation.php#url=https://raw.githubusercontent.com/Jeredpoi/Br-script/main/verdict.user.js)

   Запасная прямая ссылка: https://raw.githubusercontent.com/Jeredpoi/Br-script/main/verdict.user.js

   Открывай в обычном браузере (Chrome, Яндекс, Edge), а не внутри Telegram или ВК: там расширений нет, и файл просто откроется текстом.
3. Если стоит старый «Black Russia Style Forum», выключи его.

## Обновления

Обновлять вручную не нужно. Когда выходит новая версия, на форуме появляется сообщение «Вышла новая версия», жмёшь «Обновить», потом «Установить».

Настройки: значок слева внизу или Alt+V.
